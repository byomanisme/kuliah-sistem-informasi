# 📚 SEMESTER 4 — S1 SISTEM INFORMASI UNPAM

Daftar mata kuliah semester ini:

- **05 MANAJEMEN PROYEK SISTEM INFORMASI**: Perencanaan jadwal proyek, estimasi biaya, WBS, CPM, dan manajemen risiko proyek IT.
- **06 KEAMANAN SISTEM INFORMASI**: Kriptografi, keamanan jaringan, ethical hacking dasar, dan mitigasi ancaman siber.
