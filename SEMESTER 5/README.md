# 📚 SEMESTER 5 — S1 SISTEM INFORMASI UNPAM

Daftar mata kuliah semester ini:

- **01 METODOLOGI RISET**: Metode penelitian ilmiah, identifikasi masalah empiris, perumusan masalah, kajian pustaka, dan proposal skripsi.
- **02 PEMROGRAMAN MOBILE**: Pengembangan aplikasi mobile multi-platform menggunakan Flutter, Dart, state management, dan REST API.
- **03 DATA WAREHOUSE & DATA MINING**: Arsitektur OLAP/ETL, skema bintang/snowflake, algoritma clustering, klasifikasi, dan asosiasi data.
- **04 PERENCANAAN STRATEGIS SISTEM INFORMASI**: Enterprise Architecture (TOGAF / Zachman), analisis SWOT, Value Chain, dan IT Alignment.
- **05 ETIKA PROFESI SISTEM INFORMASI**: Kode etik profesional IT, regulasi UU ITE, hak kekayaan intelektual (HAKI), dan privasi data.
- **06 KERJA PRAKTIK**: Implementasi keilmuan sistem informasi secara riil pada industri / perusahaan mitra.
